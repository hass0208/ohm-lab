# 옴의 법칙 실험실

2022 개정 교육과정 중학교 과학2 「전기와 자기」 단원의 **전압·전류·저항 관계(옴의 법칙)** 가상 실험입니다.
학생이 전압과 저항을 직접 바꾸면 측정값이 자동으로 기록되고 그래프가 그려집니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 실험 1 · 전압과 전류 | 저항을 고정하고 전압을 바꾸며 전압–전류 그래프(비례) 그리기 |
| 실험 2 · 저항과 전류 | 전압을 고정하고 저항을 바꾸며 저항–전류 그래프(반비례), 1/R 그래프 그리기 |
| 실험 3 · 저항의 크기 | 물질의 종류, 전선의 길이, 단면적에 따른 저항 비교 |
| 확인 문제 | 7문항, 누르면 바로 정답과 풀이 |

## 주요 기능

- 스위치 열고 닫기, 전자의 이동 애니메이션(전류가 클수록 빨라짐), 전류의 방향 표시
- 값을 바꾸면 자동 기록, ‘자동 측정’으로 그래프 한 번에 완성
- 추세선과 기울기 해석 자동 표시, 측정 오차 켜기/끄기
- 휴대폰·태블릿·PC, 밝은 화면·어두운 화면 모두 지원

## 사용 방법

`index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 게시해 링크를 학생들에게 나눠 주세요.

> 실험값은 계산으로 만든 모의 실험값이며, 실험 3의 물질별 저항 값은 비교하기 쉽게 단순화한 값입니다.
